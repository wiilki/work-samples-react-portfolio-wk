# Will Kim — Portfolio

A fully refreshed, responsive React portfolio featuring selected websites, web apps, and backend projects.

## Current design

- An editorial-style landing page with an accessible sticky navigation, featured work, searchable/filterable project archive, about, expertise, and contact sections.
- Honest project cards with meaningful descriptions, technologies, GitHub links, and live-site links **only for projects with a known public deployment**.
- Updated previews for published work use **WordPress mShots**, an external website capture service, rather than embedding old screenshots from 2023/24. Captures can be cached or briefly unavailable. If a preview fails (or the project has no public site), the card displays a clearly labeled illustration — never a fabricated screenshot.
- Mobile navigation, visible focus states, skip link, reduced-motion support, semantic headings, and responsive grids.
- Source-only applications such as Paceboard are **not represented as currently live** until deployment is confirmed.

## Run locally

Node 20+ is recommended.

```bash
npm install
npm start
```

To validate the portfolio:

```bash
CI=true npm test -- --watch=false --runInBand
npm run build
```

## Updating projects and previews

Edit [src/data/projectData.js](src/data/projectData.js). Each entry requires an `id`, `title`, `subtitle`, `description`, `category`, `tags`, `repo`, and `tone`. Add a `live` field **only** when the public website is actually deployed. The card then requests a fresh screenshot from the published URL. Screenshot images are automatically generated by a third-party service, which may cache results and is not part of this repository.

Do not add private, local-only dashboards or unreleased preview URLs as public links. Live apps can change independently of this portfolio; confirm a live URL before listing it.

## Deployment

The repository is connected to a Vercel project: [portfolio](https://work-samples-react-portfolio-wk-bfdd.vercel.app/). A successful commit to `main` should be automatically deployed if that integration remains enabled.
